## 🛠️ What I'm building

One idea runs through my open-source work: **help developers work better with AI**, at the lowest token cost, with the developer in control.

- [**RefDex**](https://github.com/danielonet/refdex): code index for AI assistants over MCP, so tasks use fewer tokens. On the [VS Code](https://marketplace.visualstudio.com/items?itemName=danielonnet.refdex) and [JetBrains](https://plugins.jetbrains.com/plugin/34561-refdex) marketplaces.
- [**app-brain**](https://github.com/danielonet/app-brain): agent-written, human-approved docs that agents read over MCP instead of re-reading the code.
- [**Pyrite**](https://github.com/danielonet/pyrite): read Python as if it were Java. Supervised AI development for [VS Code](https://marketplace.visualstudio.com/items?itemName=danielonnet.pyrite).
- [**trafilatura-java**](https://github.com/danielonet/trafilatura-java) · [**jusText-java**](https://github.com/danielonet/jusText-java): clean text extraction and boilerplate removal, on Maven Central.
- [**Heimdall**](https://github.com/danielonet/heimdall): home SOC and NOC in one box.
- [**Midnight Fox**](https://github.com/danielonet/midnight-fox): Firefox dark mode that remaps colors instead of inverting them.
