### 🛠️ What I'm building

Most of my open-source work is about one idea: **helping developers work better with AI**. That means giving AI assistants the right context at the lowest token cost, and keeping the developer in control of the code the AI writes.

#### AI developer tools

| Project | What it does |
| --- | --- |
| [**RefDex**](https://github.com/danielonet/refdex) | A code index for AI assistants. Claude Code, GitHub Copilot and Junie look code up through MCP instead of reading whole files, so tasks use fewer tokens and large codebases stay navigable. On the [VS Code](https://marketplace.visualstudio.com/items?itemName=danielonnet.refdex) and [JetBrains](https://plugins.jetbrains.com/plugin/34561-refdex) marketplaces. |
| [**app-brain**](https://github.com/danielonet/app-brain) | A knowledge base for your code: AI agents write plain-language documentation, people review and approve it, and agents read the approved docs over MCP instead of re-reading the code. Includes a VS Code front end with a dependency graph and cost tracking. |
| [**Pyrite**](https://github.com/danielonet/pyrite) | Read Python as if it were Java. A VS Code extension that lets Java developers review AI-written Python with confidence: supervised development instead of vibe coding. On the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=danielonnet.pyrite). |
